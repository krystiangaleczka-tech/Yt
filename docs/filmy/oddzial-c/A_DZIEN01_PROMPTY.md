# Dni 1–1 · prompty obrazów (wariant A)

Każdy prompt jest pełny: można go wkleić w dowolny generator obrazów bez kontekstu. Styl, postacie i lokacje są takie same we wszystkich, żeby kadry były spójne. Ruch kamery z rozpiski robi się w montażu — prompt opisuje kadr w kluczowym momencie ujęcia. Napisy (kartki, karty dni, HUD) dodaje się w Studio, nie w generatorze.

**Negative prompt** (jeśli generator go obsługuje):

```
photorealistic, 3D render, anime, manga, glossy, detailed shading, gradients, text, subtitles, watermark, logo, extra fingers, extra limbs, gore, blood splatter, frame border
```
