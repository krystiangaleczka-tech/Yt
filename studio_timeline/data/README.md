# Land polygons

`land-110m.json` derives from Natural Earth 1:110m land, version 4.0.0, rounded to 0.001° for a compact offline base map. This scale is for documentary context, not navigation. The renderer uses an equirectangular projection; project bounds, points, routes and captions are independent of the map data.

Source: https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/

Original: https://naturalearth.s3.amazonaws.com/110m_physical/ne_110m_land.zip

Natural Earth data are public domain: https://www.naturalearthdata.com/about/terms-of-use/
