Odpowiedź Claude

Claude Code (bez kopiowania)

Program zapisuje paczkę do pliku. W Claude Code napisz oceń paczkę Book Scout. Claude przeczyta plik i zapisze oceny obok, a Ty klikasz „Importuj z plików”.

Co ocenia Claude

  • Ciekawość 0–100: czy z książki wyjdzie film dla szerokiej widowni
  • Trudność 1–10: dostęp do źródła, język, research, materiały
  • Materiały wizualne, godziny researchu, potencjał na serię i Shorts
  • Tytuł filmu, hook, pytanie centralne i fraza do sprawdzenia konkurencji
  • Ryzyka: kontrowersje, demonetyzacja, prawa autorskie

Kanał i koszty

Klucz Google (YouTube + Google Books)

Bez klucza działa wszystko poza wynikami YouTube i Google Books. Popyt liczony jest wtedy z Wikipedii, a YouTube można sprawdzić przez Claude Code.

  1. W Google Cloud Console włącz YouTube Data API v3 i Books API.
  2. Utwórz klucz API (Dane logowania → Utwórz → Klucz API).
  3. Wpisz go do pliku bookscout/.env: GOOGLE_API_KEY=… i uruchom ponownie Book Scout.

Darmowy limit YouTube to 10 000 jednostek dziennie. Jedna analiza tematu zużywa ok. 102, czyli około 95 tematów dziennie.

Jak liczony jest wynik

  • 25% ciekawość, 20% popyt, 15% wolne pole (100 − konkurencja), 15% wyjątkowość źródła, 15% ROI, 10% łatwość
  • Ratio = popyt / konkurencja. Powyżej 1,5 to luka.
  • Wyjątkowość = ciekawość × brak wersji cyfrowej (+15% bez angielskiego wydania)
  • Prognozy są orientacyjne (±50–100%) i służą do porównywania tematów.
